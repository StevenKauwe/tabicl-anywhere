BrowserTabICL

Teach a model from a table of examples, then ask it about new rows. It all happens in this browser tab.

Your data never leaves this browser. The table you choose is read and worked on by your own computer; nothing is uploaded, and there is no server behind this page to receive it. The only thing fetched from the internet is the general-purpose model itself, which knows nothing about you. What you fit is stored in this browser only, until you delete it or its time runs out.

1The model

A ready-trained model does the work. It is downloaded once and then kept in this browser, so later visits start at once. It is fetched automatically when first needed; you can also fetch it now.

2Your table of examples

Drop a CSV file here, or choose one. The first line must hold the column names. One column is what you want predicted; the others are what to predict it from. Text columns and empty cells are fine.

It holds

The model looks at your table several times with the columns shuffled, and averages the answers. More members give steadier answers and take proportionally more time and storage. The number is preset to suit the size of your table.

More options

Compact storage changes answers only in the fourth decimal place or beyond.

Both give the same answers. The graphics card is used only where this browser offers one to web pages.

3Fit

Fitting runs your table through the model once and keeps the result, called a fitted model, in this browser. The page stays usable while it works.
